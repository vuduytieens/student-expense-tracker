# Student Expense Tracker 

(A simple command-line application written in C++ to help students track and manage their daily expenses)

## Features
- Add new expenses
- View all expenses
- Search expenses by category or description
- Calculate total spending
- View spending statistics by category
- Save and load expense data
- Run the application with Docker

## Technologies
- C++
- STL
- Data Structures
- File I/O
- Git & GitHub
